# GARVEE SEO 内容增长与销售额外激励方案

商品开发专业知识 → 高质量内容 → 自然搜索流量 → 可归属销售 → 额外激励。

本仓库收录 GARVEE 内部「SEO 内容增长与销售额外激励计划」的整合方案，合并自两份原始文档：

- ①《GARVEE SEO 内容增长与销售额外激励计划说明》——业务方案：参与原则、5% 激励池与角色分工、内容流程、归因与结算规则。
- ②《项目范围与产品 MVP 方案》——系统方案：角色权限、状态流转、唯一标识、归因实现与验收标准。

## 内容结构（15 节）

1. 项目结论与范围（已确定 / 待评审）
2. 要解决的问题
3. 参与边界与核心原则
4. 为什么值得做
5. 角色、权限与职责
6. 激励池与分配比例（含占池可视化）
7. 内容生产与发布流程
8. 选题与内容质量机制
9. 归属规则：自然搜索识别与唯一归属
10. 合格净商品销售额与退款
11. 产品方案（MVP）
12. 各角色数据视图
13. 试点建议
14. 验收标准
15. 待评审决策清单

## 需要业务评审确认的关键冲突

原两篇文档的激励口径不能同时成立，本稿未擅自消解，已在正文第 6 节与第 15 节标注：

- 业务方案：总池 **5%**，作者 3.8% / 负责人 0.3% / 编辑 0.6% / SEO 0.3%
- 系统方案：按合格净商品销售额 **1%~3%** 计提

作者 3.8% 已超过 3% 上限。收敛路径：采纳 5% 池并删除 1%~3% 表述，或下调作者比例重算分配表；无论哪种，比例必须参数化可配置，并把比例版本写入每条激励记录，后续调比例不追改历史结果。

## 口径边界

文中「可归属自然搜索销售额」不等于全部新增销售额；所有激励比例为提案值，最终以业务评审与财务确认口径为准。
